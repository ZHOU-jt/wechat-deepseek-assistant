# 微信 DeepSeek 聊天助手

在 Windows 上运行的个人微信聊天助手，使用 DeepSeek API 生成文字回复。
消息读取使用本机数据库，发送使用微信主窗口控件，不需要为每个聊天打开独立窗口。
这不是微信官方接口项目。

## 功能

- 指定群聊：仅在消息以配置的触发词开头时回答，普通文字也纳入群上下文。
- 可选的所有普通好友私聊自动回复，无需触发词。公开版默认关闭，请自行勾选。
- 每个会话保存最近 40 条背景文字，每位发言人保存最近 5 轮完成的问答。
- 群聊和私聊分别隔离，缓存按条数淘汰，重启后保留。
- API Key 与历史缓存通过 Windows 当前用户 DPAPI 加密保存。
- 数据库消息去重、搜索目标身份核对、发送前核对会话标题、发送后数据库确认。
- 支持自定义模型、触发词和提示词。

## 环境要求

- Windows 10/11 或 Windows Server 2022，64 位，Python 3.12，含 Tcl/Tk 和 Python Launcher。
- 当前适配微信 **4.1.15.56**，读取恢复对程序版本和 DLL 哈希有严格校验。
  升级微信后可能无法运行，不能通过删除校验来假定兼容。
- 有效的 DeepSeek API Key；模型名以账户实际可用的名称为准，界面允许修改。
- 微信已登录，Windows 桌面可交互。锁屏、注销、重新扫码等情况不能靠服务器开机解决。

## 安装和使用

1. 下载源码压缩包并解压到固定目录，或克隆本仓库。
2. 安装 Python 3.12 x64（包含 Tcl/Tk 和 Launcher），双击 `install.cmd`。
3. 自行安装并登录兼容版本的微信。本项目不分发微信程序或登录资料。
4. 双击 `start.cmd`。填写 Key、完整群名（每行一个）、触发词和提示词。
5. 按需启用好友私聊，点击保存设置、检查微信读取、测试 API，然后启动自动回复。
6. 从另一个账号发送一条新消息验收。检查读取成功不等于实际收发已验证。

群触发示例：触发词为 `@助手` 时发送 `@助手 你好`，触发词后使用空格或冒号。
启动前的旧消息不补答。发送期间不要手动切换微信会话；同名联系人请设置唯一备注。

设置保存在 `assistant/settings.json`，提示词在 `assistant/prompt.txt`。
Key 和缓存位于 `assistant/cache/`。这些路径均被 Git 忽略，**不要提交或公开上传**。
换 Windows 用户或换机器后，原 DPAPI 加密数据通常不能直接解密。

## Windows 服务器

先连接桌面、登录微信、打开助手并启动监听。离开时，在服务器上右键
`disconnect-keep-desktop.cmd`，以管理员身份运行并确认，把当前 RDP 会话交接到控制台。
这不会配置 Windows 自动登录、修改锁屏策略，也不会替微信扫码登录。
此前的便携部署版使用 `4-disconnect-keep-desktop.cmd`；这里的脚本用于源码安装布局。

服务器持续运行不保证微信永久在线。微信要求手机确认或扫码时，需要人工处理。
目前尚未实现掉线后的自动重新登录和自动恢复监听。

## 测试

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -p "test_*.py"
```

测试使用模拟消息库和控件，不读取真实微信聊天、不调用 DeepSeek、不发送消息。
部分测试验证 Windows 加密与 COM 接口，因此需要 Windows 环境。
主窗口收发已在实际部署环境验证；仍需在每台新机器上验收。
发布检查中，快速连续写入临时加密缓存曾出现间歇性失败，随后完整重跑 106 项通过；
该现象的具体原因尚未定位，不代表已经修复。如遇“加密缓存保存失败”，请保留原缓存并排查。

## 打包

```powershell
py -3.12 tools/build_release.py
```

在 `dist/` 生成完整源码包，包含安装脚本、说明和测试；不含 Python 运行时、
微信程序、个人设置、Key 或聊天数据。源码包解压后按上述安装流程运行。
不要直接把整个已使用的工作目录压缩公开。

## 结构

- `assistant/app.py`：设置界面与工作进程管理。
- `assistant/account_worker.py`：主窗口群聊和私聊调度。
- `assistant/message_source.py`：只读数据库快照和消息去重。
- `assistant/core.py`、`secure_storage.py`：模型请求、上下文、加密持久化。
- `assistant/main_window_sender.py`、`search_adapter.py`、`conversation_guard.py`：定位和核对发送目标。
- `assistant/delivery.py`：发送结果核验。
- `assistant/accessibility_recovery.py`：特定版本的 UIA 可访问性恢复，会修改微信进程中的可访问性标志。
- `assistant/vendor/`：第三方数据库处理代码及原许可证。
- `tests/`：回归测试；`tools/`：可重复打包工具。

## 已知边界与数据流

仅支持新文字消息，未接入图片生成、语音识别或文件处理。每次请求会将提示词、
当前问题、当前会话相关背景与个人问答上下文发送至 `api.deepseek.com`。
不是微信官方机器人服务；依赖客户端数据库结构、版本与桌面状态，不能承诺长期无人值守。
先在有参与者知情的测试会话验证，再启用实际群聊或所有好友回复。
